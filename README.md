# Beach Blue Blog

Cấu trúc:

- `index.html`: trang chủ
- `about.html`: giới thiệu
- `contact.html`: liên hệ
- `posts/`: bài viết riêng
- `assets/css/style.css`: toàn bộ giao diện Beach Blue
- `assets/js/main.js`: dark mode, mobile menu, bộ lọc bài viết, demo form

## Đưa lên GitHub Pages

1. Upload toàn bộ file và thư mục vào repository.
2. Vào Settings → Pages.
3. Chọn Deploy from a branch.
4. Branch: main.
5. Folder: /(root).
6. Save.

## Chỉnh sửa nhanh

Tìm và thay:
- `Beach Blue` → tên blog của bạn
- `Minh Nguyễn` → tên bạn
- `hello@example.com` → email thật
- các link Facebook/GitHub/LinkedIn `href="#"` → link thật

## Lưu ý

Ảnh đang dùng `picsum.photos` để demo. Bạn có thể thay bằng ảnh của mình trong `assets/images/` và đổi `src` tương ứng.
Form liên hệ/newsletter hiện là front-end demo, chưa kết nối backend.
